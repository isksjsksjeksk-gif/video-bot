কুকি কীভাবে দেবেন (YouTube / Instagram / Facebook / Twitter এর জন্য)
=====================================================================
১. কম্পিউটারের Chrome/Firefox এ এক্সটেনশন ইনস্টল করুন: "Get cookies.txt LOCALLY"
২. একটা ফালতু/নতুন অ্যাকাউন্ট দিয়ে youtube.com, instagram.com, facebook.com, x.com এ লগইন করুন
৩. প্রতিটা সাইটে গিয়ে এক্সটেনশন থেকে Export চাপুন, সবগুলো লেখা একটা ফাইলে জোড়া দিন
   (প্রথম লাইন "# Netscape HTTP Cookie File" একবারই থাকলেই হবে)
৪. Render → আপনার সার্ভিস → Environment → Add Variable
      Key:   COOKIES
      Value: পুরো লেখাটা পেস্ট করুন
৫. Save → Manual Deploy

⚠️ cookies.txt কখনো পাবলিক GitHub এ আপলোড করবেন না।
